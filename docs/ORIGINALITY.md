# Design Comparison

This document describes the mechanism distinction relevant to AccordSpace. It is not a patent claim, global novelty claim, or prediction of Portal acceptance.

AccordSpace is not merely an AI consistency label. Its defining protocol object is a vector of separately owned executable conditions over one frozen finite domain.

The mechanism combines four properties:

1. **Per-condition semantic compilation.** Each natural-language condition becomes a typed predicate.
2. **Full-domain behavioral agreement.** Independent results are compared over every declared assignment, rather than only comparing explanations or the aggregate feasible result.
3. **Exhaustive bounded diagnosis.** The protocol enumerates all inclusion-minimal conflict and correction sets with witnesses.
4. **Owner-held relaxation and unanimous commitment.** Only the owner of a condition can waive it; every waiver creates a new revision, and commitment requires every participant to approve the same feasible world.

These properties are interdependent. Comparing only the aggregate feasible set can hide semantic disagreements that become visible after a waiver. A generic AI verdict does not provide the deterministic state machine, exhaustive witnesses, owner authorization, or revision invalidation.

Natural-language compilation, constraint solving, and minimal unsatisfiable-core enumeration are established techniques. The project does not claim to have invented those primitives individually. Its contribution is their bounded combination with independent semantic consensus, owner authorization, revision invalidation, and unanimous onchain commitment.

The repository contains the complete implementation and protocol specification so the mechanism can be evaluated directly rather than inferred from promotional language.
