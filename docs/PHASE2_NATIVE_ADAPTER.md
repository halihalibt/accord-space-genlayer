## SDK boundary

The contract stores complete immutable-value session snapshots as canonical JSON
strings in real SDK `TreeMap[str,str]` storage. A numeric counter and string-key
index provide bounded pagination. Raw ABI address values are normalized through
the actual SDK `Address` constructor. The creator must be a roster member; each
other member still joins only by sealing their own conditions. Named wallets are
never treated as having approved merely because someone listed them.

`compile_session(session_id)` is permissionless but accepts NO AST, mask, sender,
or result argument. It freezes plain memory JSON and prompt strings, then invokes
`gl.vm.run_nondet_unsafe` with two nested callbacks. The Leader compiles and strictly
parses; the Validator invokes its own model compilation and compares every
condition's status and full finite-domain behavior. Neither callback captures
`self` or a storage proxy. Errors reject; they are never converted to UNKNOWN.
Application state is saved only after the native block returns and the snapshot
has been rechecked. Honest but syntax-different equivalent ASTs may agree.

## Raw JSON and the test-only mock correction

Pinned SDK overloads define `response_format='text'` as a string and JSON mode as
a decoded dictionary. The contract deliberately uses TEXT mode plus a strict JSON
parser. JSON mode would destroy duplicate-key evidence before the parser sees it.

genlayer-test 0.29.2's `_handle_llm_request` auto-decodes any mocked JSON string,
even when the request explicitly asks for text. `tests/direct/conftest.py` applies
a narrow test-only correction: a text-format request returns its registered mock
string unchanged; all other behavior remains in the official test framework.
Installed SDK/test-package sources are not modified. Tests still run actual SDK
storage, calldata boundary, callbacks and pickling. The correction must not be
confused with proof of real host/provider behavior; verify raw-text behavior on
Stable before deployment approval. Duplicate-key rejection is tested explicitly.

## Interface

| Method | Kind | Ownership / effect |
|---|---|---|
| create_session(id, participants, domain_json) | write | creator in roster; unique ID; participant addresses and domain frozen |
| seal_conditions(id, conditions) | write | actual runtime sender seals only own text once |
| compile_session(id) | write | anyone once ready; native semantic consensus; no supplied result |
| waive_condition(id, clause_id, expected_hash) | write | actual condition owner only; revision increments and all approvals clear |
| approve_plan(id, world_id, expected_hash) | write | actual member only; unanimous same feasible plan commits |
| cancel_session(id) | write | actual member; nonfinal only |
| get_session(id) | view | full public canonical snapshot |
| get_state_hash(id) | view | current constraint revision identity |
| list_sessions(offset,limit) | view | deterministic index, limit 1–20 |
| get_protocol() | view | protocol/prompt version and planned network |

No constructor arguments, admin override, raw-result write, hidden backend signer,
payable flow or user-supplied sender. No automatic retry or Appeal code.

## Validation and limits

- 24 inherited deterministic tests, including 4,681 oracle families.
- 22 SDK Direct Mode tests: actual storage roundtrips, complete lifecycle,
  independent callback execution with changed mocks, equivalent AST acceptance,
  hidden per-owner disagreement rejection, malformed output, explicit UNKNOWN,
  owner-only waiver, stale approvals, outsider permissions, index bounds,
  no post-compilation model calls, callback pickling and public ABI checks.
- Native lint and SDK semantic validation pass; 6 writes, 4 views, 0 constructor
  arguments. This is not a full formal audit or real WebAssembly/network run.

Direct Mode applies the Leader result provisionally before a captured Validator
is invoked by tests. One test uses the SDK snapshot/revert facility to model
discard after rejection. This is an explicit test harness recovery, NOT evidence
that a real committee agreed or discarded a receipt. Real model agreement,
latency, execution cost, Stable runner availability, chain identity and finality
remain unverified. The prior workspace Stable RPC result was HTTP 403; this batch
did not repeat the same blocked requests. No alternate network was selected.

The exhaustive solver proves facts about accepted bounded predicates, not their
faithfulness to real-world language. Test prompt/data separation does not prove
remote-model prompt injection resistance.
